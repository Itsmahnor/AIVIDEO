# Web package

Vite + React wizard: brand, options, description, screenshots, generate, live preview, MP4 render.
Start it with `npm run dev:web` (the API must be running: `npm run dev:api`). Opens at http://localhost:5173.
The preview uses `@ai-video-studio/video/player` (the same DynamicVideo composition Remotion renders). Remotion's `public` folder is shared via `publicDir`.
